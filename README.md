# VizualniVyvojoveProstrediaGeneratorKodu
Vytvořte v prostředí Visual Studio (jazyk C#) desktopovou aplikaci pro Windows Forms s verzováním na GitHubu. Aplikace bude sloužit jako editační prostředí pro tvorbu algoritmů pomocí vývojových diagramů a jejich následný převod do spouštěcího kódu.

Uživatel bude na plátno vkládat bloky (Start/Konec, Vstup/Výstup, Přiřazení proměnné, Podmínka IF, Cyklus WHILE) a řadit je či propojovat do logické posloupnosti. Vyhodnocování výrazů zadaných v blocích bude realizováno pomocí zjednodušeného vyhodnocovače nebo vestavěných .NET systémových knihoven.

Aplikace umožní generovat odpovídající zdrojový kód (v C# nebo pseudokódu) a simulovat jeho spuštění s výstupní konzolí a zobrazením stavu proměnných. Vytvořené diagramy bude možné ukládat a načítat do souborů ve formátu JSON nebo XML.
